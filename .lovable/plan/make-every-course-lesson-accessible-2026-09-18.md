# Make every course lesson accessible

## What will change
- Turn every lesson title into a clear **Open lesson** link instead of a static outline row.
- Add a focused lesson reader with the lesson objective, guided explanation, practical steps, code or terminal examples, an exercise, and a completion checklist.
- Cover Ubuntu Linux, all three C++ levels, and ROS 2 Lyrical Luth using the existing verified curriculum and official references.
- Add a clear **Start course** action at the top of each free course; enrollment remains optional and does not block lessons.
- Keep Industrial Robots protected: visitors can inspect its syllabus, but lesson access will unlock only after the confirmed $30 purchase.

## Navigation and access
- Free lesson URLs will be shareable and directly accessible from each course page.
- Each lesson page will include Previous lesson, Next lesson, and Back to course links.
- Missing lesson URLs will show a helpful not-found state rather than a blank page.

## Validation
- Check every lesson link on desktop and mobile.
- Verify direct lesson URLs, keyboard focus, browser back navigation, and no console errors.
- Confirm paid lessons remain unavailable without an active purchase.
