# Expand RobotCodeHub into a teaching-first course library

## Goal
Turn the existing lesson pages from short code samples into guided lessons that explain concepts before asking learners to run code. Update the site brand and public domain references to RobotCodeHub and `www.robotcodehub.com`.

## Course improvements
- Introduce a shared lesson structure: what the learner will understand, plain-language concept explanation, prerequisites, annotated commands or code, step-by-step practice, expected output, common mistakes, troubleshooting, exercise, and completion checks.
- Expand Ubuntu lessons around safe system setup, terminal literacy, packages, permissions, networking, and a repeatable ROS 2 workstation setup.
- Expand C++ beginner, intermediate, and advanced lessons with line-by-line reasoning, robotics examples, compilation commands, output interpretation, tests, and progressively harder exercises.
- Expand ROS 2 Lyrical Luth lessons around the ROS graph, workspaces, packages, nodes, topics, services, actions, parameters, launch, diagnostics, and modern C++ patterns.
- Expand all seven Industrial Robots lessons with model-specific concepts, code walkthroughs, safe simulation-first workflows, expected behavior, failure recovery, and practical projects.
- Keep official documentation links and clearly label safety boundaries; do not invent unsupported package availability or hardware instructions.

## Page experience
- Redesign the lesson reader for long-form learning while preserving the current soft workshop style.
- Make explanations visually distinct from commands, output, warnings, exercises, and checkpoints.
- Preserve previous/next navigation, course outlines, free access, and the paid Industrial Robots access gate.
- Ensure course and lab pages link learners to the relevant expanded lessons.

## Brand and domain
- Replace user-facing `RobotHub` naming with `RobotCodeHub`.
- Use `https://www.robotcodehub.com` for canonical public-domain references where appropriate.
- Do not treat the domain as the legal seller identity; payment policy seller wording remains pending the owner’s legal name.

## Validation
- Check every course level, ROS 2 lab, paid lesson gate, and homepage link on desktop and mobile.
- Run the project’s type checks and confirm there are no browser errors or overflowing lesson content.
